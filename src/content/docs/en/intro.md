Welcome. This site holds the technical documentation for the
projects I build and operate. Content is structured step-by-step:
overview first, then architecture, installation, and usage.

## Active projects

### MailGate

Universal email platform with plugins. Self-hosted mail server
(SMTP + IMAP + Storage + Auth in a single `.deb`) with webmail,
admin dashboard, multi-tenancy, Telegram-2FA, Vaultwarden sidecar
for passwords, and Radicale sidecar for calendar/contacts.

→ [MailGate overview](/en/mailgate/overview/)

### PoolX

Online pool platform — organise participants, manage pools,
integrated payment. Web app on Next.js with FastAPI backend.

→ [PoolX overview](/en/poolx/overview/)

## How this docs site is organised

Each project has four tabs in the sidebar:

1. **Overview** — what it is, what it solves, who it's for
2. **Architecture** — tech stack, components, data flow
3. **Installation** — from empty server to running instance
4. **Usage** — typical workflows after installation

Switch language top-right (DE / EN). The German version is the
primary source — English translations follow.
